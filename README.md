Projet : WeatherDesk
Type : Application de bureau (Projet de licence)
Technologies : Electron.js, JavaScript, HTML/CSS, OpenWeatherMap API, OpenStreetMap, Icônes météo OpenWeather

Description :
Dans le cadre de ma licence en développement d’applications, j’ai réalisé une application de bureau nommée WeatherDesk avec Electron.js. Cette application fournit des informations météo précises et interactives en fonction de la localisation de l’utilisateur ou d’une ville choisie sur une carte dynamique.

Fonctionnalités principales :
📍 Géolocalisation automatique : détection de la position actuelle de l’utilisateur pour afficher la météo locale

🏙️ Recherche de ville : l’utilisateur peut saisir une ville pour consulter sa météo

🗺️ Carte interactive (OpenStreetMap) : possibilité de cliquer sur une ville de la carte pour afficher les données météo correspondantes

🌦️ Données météo en temps réel grâce à l'API OpenWeatherMap :

Temps actuel (ex. : ciel dégagé, pluie, neige...)

Température

Prévisions météo sur 3 jours

🎨 Icônes météo personnalisées fournies par OpenWeatherMap pour une meilleure expérience visuelle

Exemple d’affichage :

Météo actuelle à Ottmarsheim
Temps : ciel dégagé ☀️
Température : 21.1°C
Prévisions sur 3 jours : ciel clair, températures modérées
